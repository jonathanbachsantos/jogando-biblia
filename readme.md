# 🎮 Curso: Criando Meu Primeiro Jogo Bíblico com JavaScript e Phaser

Este curso é focado em ensinar **Lógica de Programação** utilizando o motor de jogos Phaser como ferramenta visual.

## 🚀 Jornada de Aprendizado

| Aula | Conceito de Programação | Objetivo no Jogo |
| :--- | :--- | :--- |
| **1** | Variáveis e Constantes | Criar o personagem e definir nomes e pontos. |
| **2** | Operadores e Coordenadas | Mover o personagem alterando X e Y. |
| **3** | Objetos e Configurações | Criar as animações (frames) do personagem. |
| **4** | Expressões Matemáticas | Sistema de pontuação ao coletar itens. |
| **5** | Funções e Parâmetros | Organizar o código para criar itens aleatórios. |
| **6** | Estruturas Condicionais | Sistema de vida, dano e invencibilidade. |
| **7** | Estruturas de Repetição (Loops) | Criar vários inimigos e obstáculos de uma vez. |
| **8** | Organização e Estados (Cenas) | Finalizar o jogo com Menu, Jogo e Vitória. |

## 🛠️ Como usar

Para rodar uma aula específica, altere a tag `<script>` no arquivo `index.html`:
```html
<script src="aula1.js"></script>
```
